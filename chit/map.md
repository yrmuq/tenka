# Repository map

- `crates/tenka-core/src/lib.rs` exposes automatic conversion policy, image inspection, and the JPEG XL/WebP codec and measurement API.
- `crates/tenka-core/src/raster.rs` handles input validation, color and orientation normalization, resizing, and reference-scale SSIMULACRA2 scoring.
- `crates/tenka-core/src/jxl_header.rs` validates JPEG XL dimensions, bit depth, and animation before decoding files for comparison.
- `crates/tenka-gui/src/main.rs` implements the conversion window and routes batch work through a background worker.
- `crates/tenka-gui/src/about.rs` renders About, reads attribution rows from the README, and opens the hidden window settings from the logo.
- `crates/tenka-gui/src/window_size.rs` renders the Secret menu and manages its window size, title, and toolbar layout settings.
- `crates/tenka-gui/src/image_info.rs` loads image and filesystem metadata, shows the details dialog, and opens the previewed file in its default viewer.
- `crates/tenka-gui/src/updates.rs` checks GitHub for a newer stable release when requested from About.
- `crates/tenka-gui/src/jobs.rs` bridges the desktop interface to the library, scans imported folders, probes queued file sizes and dimensions, and handles file saving and desktop opening requests.
- `crates/tenka-gui/src/estimate.rs` estimates remaining batch time from input byte sizes, pixel counts, and recent conversion timings.
- `crates/tenka-gui/src/summary.rs` accumulates conversion counts, saved output sizes, and active time across pause and resume.
- `crates/tenka-gui/src/comparison.rs` runs the comparison window and synchronizes zoom and pan between full-resolution images.
- `crates/tenka-gui/src/language.rs` loads the English and Russian catalogs from `languages/`.
- `crates/tenka-gui/src/theme.rs` applies app colors and follows system appearance through the Linux settings portal for both windows.
- `crates/tenka-gui/src/window_icon.rs` provides desktop icon metadata for standalone AppImages on Wayland.
- `crates/tenka-gui/src/icons.rs` draws the language, appearance, and comparison buttons.
- `crates/tenka-gui/src/file_drop.rs` reads dropped file paths from egui for both windows.
- `packaging/` builds the AppImage with its X11 keyboard libraries and stable update metadata. The shared build action tests the workspace and starts the AppImage on X11 and Wayland.
- `.github/workflows/dev.yml` updates the development draft. `.github/workflows/release.yml` publishes stable AppImages and syncs the version to dev.
- `.github/dependabot.yml` and the deps and pins workflows group updates on deps and publish verified dependency prereleases.
- The Dependabot queue and checks workflows test the current PR merge snapshot before merging it into deps and removing the bot branch.
